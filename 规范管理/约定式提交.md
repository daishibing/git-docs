# 约定式提交

约定式提交（Conventional Commits）是一种 Git 提交信息规范，通过统一提交格式，提高提交记录的可读性和可维护性

# 提交格式

```text
<type>[(<scope>)][!]: <description>
```

参数说明：

- `type`：提交类型（必填）
- `scope`：影响范围（可选）
    - 通常使用模块名、功能名或组件名
- `!`：表示破坏性修改（可选）
    - 表示此次修改会导致已有功能、接口或调用方式不兼容
    - 例如修改接口返回结构、删除已有 API、修改配置格式等
- `description`：提交描述（必填）

# 提交类型

| 类型       | 说明                  |
|----------|---------------------|
| feat     | 添加功能                |
| fix      | 修复问题                |
| refactor | 调整代码结构              |
| style    | 调整代码格式或代码风格，不影响功能逻辑 |
| docs     | 文档相关                |
| perf     | 性能优化                |
| build    | 构建系统或依赖相关修改         |
| test     | 测试相关                |
| chore    | 项目维护相关修改            |

# 提交示例

添加功能：

```text
feat(login): 添加登录功能
```

修复问题：

```text
fix(login): 修复登录鉴权失败
```

文档相关：

```text
docs(login): 添加登录接口文档

docs(login): 更新登录接口文档
```

调整代码结构：

```text
refactor(login): 调整登录鉴权逻辑

refactor(login)!: 调整登录后返回字段结构
```
