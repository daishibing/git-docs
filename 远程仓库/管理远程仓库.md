# 管理远程仓库

Git 通过远程仓库实现本地仓库与远程仓库之间的数据交换，例如获取更新和推送提交记录

常见的远程仓库平台：GitHub、GitLab、Gitee

# 查看远程仓库

查看远程仓库列表：

```shell
git remote
```

查看远程仓库详细信息：

```shell
git remote -v
```

结果说明：

- `fetch`：执行 `git fetch` 时，从远程仓库获取数据使用的地址
- `push`：执行 `git push` 时，向远程仓库上传提交记录使用的地址

# 添加远程仓库

添加远程仓库时，`fetch` 和 `push` 地址默认相同：

```shell
git remote add <name> <url>
```

参数说明：

- `name`：远程仓库名称，一般使用 `origin`
- `url`：远程仓库地址，可以使用 HTTPS 或 SSH 协议

# 修改远程仓库

默认情况下，远程仓库的 `fetch` 和 `push` 地址相同，但是有些情况下需要修改地址

修改 `fetch` 地址：

```shell
git remote set-url <name> <new-url>
```

> 默认情况下该命令修改的是 fetch 地址，同时如果 push 地址与 fetch 地址一致，则 push 地址也会同步修改

修改 `push` 地址：

```shell
git remote set-url --push <name> <new-url>
```

参数说明：

- `name`：远程仓库名称
- `new-url`：新的远程仓库地址

# 删除远程仓库

命令：

```shell
git remote remove <name>
```

参数说明：

- `name`：远程仓库名称

# 重命名远程仓库

命令：

```shell
git remote rename <old-name> <new-name>
```

参数说明：

- `old-name`：旧远程仓库名称
- `new-name`：新远程仓库名称

# 克隆远程仓库

命令：

```shell
# 克隆全部
git clone <url>

# 克隆指定分支
git clone -b <branch> <url>
```

参数说明：

- `branch`：指定需要克隆的分支名称，仅在指定分支时使用
- `url`：远程仓库地址

> 克隆完成后会自动添加远程仓库 `origin`，可以自行查看
